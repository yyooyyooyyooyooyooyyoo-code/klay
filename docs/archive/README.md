# Archive

The files in this folder are historical. They were generated during the WordPress-to-React migration, before the November 2026 cleanup (see `../CHANGELOG-2026-11-cleanup.md`), and describe the project as it was then: the old file layout, the old noindex state of some pages and the migration inventory. Treat them as a record, not as current documentation. Note that `npm run report:migration` still writes fresh copies of the migration reports to `docs/migration/` (not to this folder).
